### 👨‍💻 Sobre Mim

Sou um desenvolvedor Full-Stack com base técnica sólida em Desenvolvimento de Sistemas. Opero na interseção entre **Engenharia de Software** e **Segurança da Informação** (fundamentos de *pentesting* e *offensive security*). Meu foco não é apenas fazer o código funcionar, mas garantir que a arquitetura de dados (MER/DER) escale e que o sistema seja à prova de balas.

* 🧠 **Mindset:** Resolução de problemas complexos com código limpo.
* 🌍 **Comunicação:** Inglês Avançado (C1) — fluência para consumir documentação, debater arquitetura e atuar em times globais.
